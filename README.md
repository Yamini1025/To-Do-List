# Java Swing To-Do List

A simple desktop To-Do List application built using Java Swing.
Users can add tasks dynamically, view them in a scrollable list, and mark them as completed using checkboxes.

## Features

* Add tasks via a text field 
* Tasks appear dynamically as checkboxes
* Scrollable task list using JScrollPane
* Clean and minimal GUI built with Swing

## Tech Stack

 * Java
 * Java Swing (JFrame, JButton, JLabel, JCheckBox, JPanel)
 * Event handling with ActionListener
